# Changelog

## Unreleased

- Pinned patched versions of transitive dev dependencies through `pnpm.overrides` (mirrored in the npm `overrides` block). Dependabot could not update them (`security_update_not_possible`) because the parent packages declare ranges that cannot reach the fixed releases, and Dependabot cannot write overrides. Covers body-parser, brace-expansion (1.x and 5.x), compression, fflate, follow-redirects, ip-address, joi, js-yaml (3.x), linkify-it, markdown-it, proxy-addr and ws (7.x and 8.x), each kept inside its parent's declared major line. This resolves 26 open Dependabot alerts, including the critical proxy-addr advisory (GHSA-jqcg-44mw-7w3h, dev-only, via express in `@lhci/cli`) and the fflate alert (via jspdf, which the production bundle does not load). No direct dependency changed. Two advisories with no patched release remain open for a human disposition (extract-zip GHSA-jmr9-qjv8-65gv and GHSA-7pqw-9j4j-h8q3, dev-only, via `@lhci/cli` > lighthouse > puppeteer-core), and three advisories whose fixes lie outside the parent's declared major are deferred (basic-ftp GHSA-c475-qrg2-pj4r, minimatch GHSA-g3hv-75wg-m249, zod 3.x GHSA-mrhx-c7xc-m3w5 under chromium-bidi; none are Dependabot alerts) (task-0bc94149).
- EDGE-105 — Edge Session detail timeline now renders a dedicated MCP lane below the P0 hook timeline. The lane surfaces `mcp.server.connected/failed`, `mcp.tool.pre/post/failed`, and `approval.*` (when `layer=mcp`) events with chip-toggle filters (Servers / Tools / Approvals / Failures) that persist via the `?mcp_lane=` URL query. Clicking a row expands an inline inspector showing upstream server, tool name, decision, approval link (`/approvals/<ref>`), and redacted args/result, plus an artifact-pointer chip when an artifact URI is present. A client-side defense-in-depth sanitizer (`src/lib/redaction.ts`) enforces the project's `_redacted`-suffix contract: server-side redaction is trusted verbatim; bare sensitive fields are replaced with `"[redacted by client sanitizer]"` before display. Reuses the existing `AgentActionEvent` typed payload — no new transformer, no P0 lane reorder. Strict axe gate passes (0 violations). Reduced motion is honored automatically via the global `<MotionConfig reducedMotion="user">` wrapper (task-a04699dc).
